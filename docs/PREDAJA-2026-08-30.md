## Kako napraviti release (mora se raditi lokalno — traži Flutter + .NET)

Buildovi (APK i `.exe`) se ne mogu napraviti u ovom okruženju; napravi ih na
mašini sa instaliranim Flutter i .NET SDK 8. Koraci:

1. **Provjeri da sve kompajlira** (obavezno prije predaje):
   ```powershell
   dotnet build backend/app.sln -c Release
   dotnet ef migrations add VerifyProbe --project backend/SOH.Services --startup-project backend/SOH.WebAPI
   #   → migracija MORA biti prazna (nema zaostalih model promjena); ako jeste, obriši je
   ```
   ```powershell
   cd mobile;  flutter analyze;  cd ..
   cd desktop; flutter analyze;  cd ..
   ```

2. **Napravi buildove** (skripte su u `scripts/`):
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\mobile-build-android.ps1
   #   → mobile/build/app/outputs/flutter-apk/app-release.apk
   powershell -ExecutionPolicy Bypass -File .\scripts\desktop-build-windows.ps1
   #   → desktop/build/windows/x64/runner/Release/desktop.exe
   ```

3. **Spakuj arhivu** `fit-build-2026-08-30.zip` sa strukturom (cijeli desktop
   `Release\` folder, ne samo `.exe`):
   ```
   fit-build-2026-08-30.zip
   ├── mobile/app-release.apk
   └── desktop-windows/           (cijeli sadržaj build\windows\x64\runner\Release\)
       ├── desktop.exe
       ├── flutter_windows.dll
       ├── *.dll (plugin biblioteke)
       └── data/
   ```

4. **Napravi immutable release** na GitHubu (tag na trenutnom `main`):
   ```powershell
   git tag predaja-2026-08-30
   git push origin predaja-2026-08-30
   ```
   Zatim na GitHubu: Releases → Draft a new release → tag `predaja-2026-08-30`
   → naslov "Predaja 30.08.2026 (dorada)" → priloži `fit-build-2026-08-30.zip`
   → Publish. (Ili `gh release create predaja-2026-08-30 fit-build-2026-08-30.zip
   --title "Predaja 30.08.2026 (dorada)"`.)

> Napomena o sigurnosti: `backend/.env-tajne.zip` je u repozitoriju sa šifrom
> "fit". To je namjerno za predaju (sandbox kredencijali), ali zapamti da
> committan .zip sa kredencijalima ostaje u git historiji — ako su ikad bili
> pravi (ne-sandbox) kredencijali, treba ih rotirati.
